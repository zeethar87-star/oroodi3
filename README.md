# عروضي

رفيق أسبوعي هادئ لعروض البنوك والمحافظ الرقمية السعودية: صفحة عربية واحدة تعرض العروض السارية فقط، من مصادر رسمية فقط، وتسمح بالتصفح بالبنك أو بالفئة أو **بالمتجر** (نون، كيتا، إكسترا...) أياً كان البنك المصدر.

## كيف يتحدث الموقع؟

```
أنت: بلاغ «عرض جديد» + رابط صفحة عروض رسمية
   ↓
الأتمتة: تسحب الصفحة ← ذكاء اصطناعي يستخرج ← فحوص حتمية ضد الاختلاق
   ↓
طلب دمج بجدول عربي ← أنت تضغط Merge ← الموقع يتحدث
   +
كل خميس: نقل المنتهي للأرشيف تلقائياً
```

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع كله: صفحة واحدة |
| `offers.json` | مصدر الحقيقة الوحيد للعروض |
| `merchants.json` | الأسماء الموحدة للمتاجر وصيغها البديلة |
| `data/expired-archive.json` | العروض المنتهية (لا يُحذف شيء نهائياً) |
| `data/health.json` | نبض آخر فحص وعدد العروض السارية |
| `scripts/` | الفحص، والتنظيف، والاستخراج، والمزامنة (بايثون بلا مكتبات خارجية) |
| `.github/workflows/` | الأتمتة الأربع |
| `docs/CONSTITUTION.md` | الدستور الحاكم |
| `docs/DECISIONS.md` | سجل القرارات والبدائل المرفوضة |
| `docs/FEASIBILITY.md` | دراسة جدوى تركيب الفكرة واختبار الكثافة |
| `docs/ROADMAP.md` | المراحل وحالتها |
| `docs/SETUP_AR.md` | **ابدأ من هنا:** خطوات التشغيل للمؤسس |
| `AGENTS.md` | تعليمات هيرمس وClaude Code وCodex |
