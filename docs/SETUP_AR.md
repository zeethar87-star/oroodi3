# دليل التشغيل خطوة بخطوة

مكتوب لمن خبرته في GitHub محدودة. كل خطوة تُعمل مرة واحدة فقط.

## قبل البدء: المستودع خاص أم عام؟

المستودع الآن **خاص (Private)**. نشر موقع GitHub Pages من مستودع خاص يحتاج اشتراكاً مدفوعاً (GitHub Pro أو أعلى). أمامك طريقان:

- **تجعله عاماً (Public).** محتوى الموقع عام أصلاً، والمفاتيح السرية تبقى سرية في الحالتين، والأتمتة لا تعمل إلا لبلاغاتك أنت. هذا هو الأبسط والمجاني.
  `Settings` ← أسفل الصفحة `Danger Zone` ← `Change visibility` ← `Make public`
- **تبقيه خاصاً** وتشترك في GitHub Pro.

## ١. تشغيل الموقع (GitHub Pages)

1. `Settings` ← من القائمة الجانبية `Pages`
2. تحت `Build and deployment`:
   - `Source`: **Deploy from a branch**
   - `Branch`: **main**، والمجلد: **/ (root)**
   - `Save`
3. بعد دقيقة إلى ثلاث دقائق يظهر أعلى الصفحة رابط مثل:
   `https://zeethar87-star.github.io/oroodi3/`

لا تكتب شيئاً في خانة `Custom domain` قبل شراء الدومين (القرار DEC-010).

## ٢. مفتاح الذكاء الاصطناعي (للاستخراج فقط)

1. من https://console.anthropic.com أنشئ مفتاح API.
2. **حدد سقف إنفاق شهري** من إعدادات الفوترة هناك، حتى لا يتحول خطأ برمجي إلى فاتورة.
3. في المستودع: `Settings` ← `Secrets and variables` ← `Actions` ← `New repository secret`
   - `Name`: `ANTHROPIC_API_KEY`
   - `Secret`: المفتاح
4. (اختياري) لتغيير النموذج: نفس الصفحة، تبويب `Variables` ← `New repository variable` باسم `OROODI_MODEL` وقيمته اسم النموذج. بدونه يُستخدم `claude-sonnet-5-5`.

## ٣. السماح للأتمتة بفتح طلبات الدمج

`Settings` ← `Actions` ← `General` ← أسفل الصفحة `Workflow permissions`:
- اختر **Read and write permissions**
- فعّل **Allow GitHub Actions to create and approve pull requests**
- `Save`

## ٤. اختبار أن كل شيء يعمل

1. تبويب `Actions` ← من اليسار **التنظيف الأسبوعي** ← `Run workflow` ← `Run workflow`
2. انتظر العلامة الخضراء ✅. هذا التشغيل ينشئ وسم `new-offer` أيضاً.
3. لو ظهرت ❌ افتح التشغيل واقرأ الخطوة الحمراء، أو انسخها لأي وكيل ذكي.

## الاستخدام اليومي: إضافة عروض من الجوال

1. تبويب `Issues` ← `New issue` ← **🎁 عرض جديد**
2. الصق رابط صفحة العروض الرسمية. صفحة القائمة أفضل من عرض واحد.
3. `Submit new issue`
4. خلال دقائق يرد البوت في البلاغ بإحدى ثلاث نتائج:
   - **✅ جهزت طلب الدمج:** افتح الرابط، وراجع الجدول، واضغط `Merge pull request` ثم `Confirm merge`. العروض تظهر في الموقع خلال دقائق.
   - **⚠️ تعذر سحب الصفحة:** افتح الصفحة بنفسك، وانسخ نص العرض، ثم عدّل البلاغ (`...` ← `Edit`) والصقه في خانة «نص العرض». الأتمتة تعيد المحاولة وحدها.
   - **ℹ️ لا عروض جديدة:** العروض موجودة أصلاً، أو كلها بلا تاريخ انتهاء، والسبب مكتوب في الرد.
5. اقفل البلاغ بعد الدمج.

## ما يحدث وحده بدونك
- **كل خميس فجراً:** نقل العروض المنتهية للأرشيف، وتحديث ملف الصحة، وفتح بلاغ تنبيه لو العروض السارية أقل من عشرة.
- **عند أي تعديل على الصفحة:** إعادة بناء ملف التنسيق، وفحص البيانات والكود.
